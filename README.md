# 🌐 Personal Portfolio Website

A modern, self‑made online portfolio designed to showcase my skills, projects, and personal branding as an IT professional. This portfolio serves as a digital identity helping potential employers, internship coordinators, and clients understand my capabilities at a glance.

---

## 📖 Project Description

This project is a personal online showcase portfolio website built from scratch. It allows me to present my skills, academic background, services, projects, and contact information in a clean, professional format. The website highlights my growth as an IT student and helps me stand out when applying for internships or freelance opportunities.

---

## ✨ Features

* Displays full **education background** and **4‑year academic profile**
* Showcases **skills**, **services**, and **recent projects**
* Includes **contact information** for collaboration or opportunities
* Represents your personal brand professionally as an IT student
* Designed to help companies and employers view your work during applications

---

## 🛠️ Tech Stack

* **Languages:** HTML, CSS, JavaScript (ES Modules)
* **Tools:** GitHub, VS Code
* **Hosting:** Netlify
* **Domain & DNS:** NameCheap — `Izekor-Kingsley.com`

## 🚀 Installation Instructions

### Hosted Version

Live Site: **[https://izekor-kingsley.com/](https://izekor-kingsley.com/)**

### Local Installation

1. Clone the repository to your machine
2. Open the folder in **VS Code**
3. Run the project by opening `index.html`

No framework or additional dependencies required.
